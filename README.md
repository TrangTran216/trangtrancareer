# Trang Tran Career — GitHub Pages Website

This is a static, mobile-friendly portfolio for `trangtrancareer.github.io`. It has no build step and works directly with GitHub Pages.

## Included pages

- `index.html` — Home and featured Project 2
- `about.html` — Professional background and current skill set
- `resume.html` — Resume with downloadable PDF
- `projects.html` — Completed project index
- `projects/open-fiscal-vendor-transaction-analysis.html` — Project 1 detail page
- `projects/california-procurement-intelligence-sqlite.html` — Project 2 detail page
- `contact.html` — Email, LinkedIn, and phone

## Project 2 assets

The `assets/project-2/` folder contains:

- Reproducible SQLite SQL workflow
- Six selected CSV result/validation exports
- Seven database/query-result screenshots
- Project README
- Complete downloadable evidence bundle

The 164 MB raw source CSV is intentionally not bundled with the website package. It remains available from the official California Open Data source linked on the project page.

## Publish or update trangtrancareer.github.io

1. Sign in to the GitHub account whose username is **trangtrancareer**.
2. Open the public repository named **trangtrancareer.github.io**.
3. Back up the current repository if needed.
4. Upload the contents of the `portfolio-site` folder to the repository root, replacing files with the same names.
5. Commit the changes to the `main` branch.
6. In **Settings → Pages**, confirm that deployment uses **main** and **/(root)**.
7. Wait a few minutes, then refresh `https://trangtrancareer.github.io`.
